# 工作台交互预览 v1

用于试用两步改图、固定修改栏、图片对比和回退的独立原型。没有接入生产页面或真实 LLM/生图服务；生成动作复用两张已有样例图。状态只保留在当前页面，刷新会重置。

项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 59321 --bind 127.0.0.1 --directory docs/prototypes/workbench-v1
```

打开 http://127.0.0.1:59321/ 。宽窗口并排显示提示词与图片，窄窗口使用“图片预览 / 提示词”切换，底部修改栏始终可用。

试用顺序：

1. 点击“外套换蓝色”示例，再点“更新提示词”，查看文字直接变更；然后点“生成图片”。也可以直接“更新并生图”。
2. 输入意见后直接点“生成图片”，这条意见会保留，新图仅记录当前提示词和生成条件。
3. 更换模型或工作流，直接生成。
4. 选旧图，点“从这张继续”，恢复提示词与当时设置；“只用提示词”保留当前设置。
5. 撤销恢复，或打开“创作记录”，找回按中文修改意见记录的状态与恢复前草稿。未发送意见也在草稿中保留。

提示词演示支持外套换蓝/红、背景改为月夜、增强暖色光照、“没有变化”及其组合（“没有变化”不能与其他修改组合）。其他请求会提示演示范围；英文提示词可以直接编辑。

浏览器验证：两步更新、组合操作、待处理意见不阻断生成、工作流直接切换、完整恢复/仅恢复提示词、撤销找回意见、历史同步选图、图片对比均已点击检查。1365×900、1280×600、640×700 布局检查通过；两份 JS 语法检查通过。控制台结果见交付记录。
