# V2 真实云主机联调清单

## 需要准备

- SSH 主机地址、端口和用户名。
- 认证方式：本机私钥路径、SSH Agent 或在软件中临时输入密码。
- 云端 ComfyUI 的监听地址和端口，推荐 `127.0.0.1:8188`。
- 从该 ComfyUI 环境导出的 API Format 基础文生图工作流 JSON。
- 工作流使用的实际 checkpoint 文件名。
- 如果使用 LoRA，提供工作流中固定 LoRA Loader 插槽及云端实际文件名。
- 云主机控制台显示的 SSH SHA-256 主机指纹，用于首次连接核对。

不要在聊天、项目文件或截图中发送 SSH 密码、私钥内容或私钥口令。私钥保留在本机，只需要在软件里选择路径。

## 联调顺序

1. 确认公网只需开放 SSH，ComfyUI 端口不直接暴露。
2. 新增云主机配置并执行“连接测试”。
3. 将软件检测到的主机指纹与云服务商控制台核对后保存。
4. 验证 SSH 隧道能访问 `/system_stats`、`/queue` 和 `/object_info`。
5. 导入 API 工作流，确认软件能沿 KSampler 连线自动识别正向、负向、Latent、Checkpoint 和 SaveImage 节点。
6. 使用固定 Seed、批量 1 生成第一张图片。
7. 核对 Prompt、尺寸、Steps、CFG、采样器、调度器、模型和 Seed。
8. 使用批量 2 验证多图下载与文件名防覆盖。
9. 检查本地分类目录、`manifest.json` 和 `workflow_api.json`。
10. 生图过程中关闭并重新启动软件，验证“恢复未完成”不会重新提交任务或产生重复图片。
11. 验证错误模型名、缺失节点、错误私钥和主机指纹变化时的中文错误提示。

## 通过标准

- ComfyUI 无需暴露公网即可完成生图。
- 参数与本地任务快照一致。
- 所有输出图片自动下载且可正常打开。
- 图片位于正确分类目录，没有静默覆盖或重复文件。
- 密码和私钥口令不进入 SQLite、日志、任务 JSON 或生成清单。
- 断线后能够根据原 `prompt_id` 恢复查询和下载。
