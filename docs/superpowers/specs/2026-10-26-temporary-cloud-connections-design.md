# 临时云端连接导入

用户在比较临时连接、固定域名和自动发现后选择“先做导入临时链接的功能”。本文记录此前对话中已选定的方案，直接实施这一范围。

## 意图与范围

保留本地 V3 工作台及用户数据，通过粘贴 HTTPS 地址和可选 Bearer 密钥，或导入 Colab 的 moss_connection.json 内容/文件，创建或更新一个可用于现有 ComfyUI 生图链路的连接。更新保留连接 ID、模型映射和工作流偏好。此次不新增 MOSS 模型/工作流、不搭建固定域名或自动发现服务、不执行真实 GPU 请求。

## 已选择的方案与替代方案

选择一次粘贴/文件导入并显式更新连接，适合频繁更换平台而无需新增基础设施。固定域名需要域名和隧道配置，仍不能保证后端身份；自动发现需要配对登记服务。两者留待后续。

## 行为与约束

- 设置页提供独立“导入临时连接”入口，支持新建及更新选中的 HTTPS 连接。JSON 文件按文本读取，仅接受有界 JSON，不执行内容。支持手填网址与密钥；导入后显示连接并可测试。无效输入不改变已有连接。
- 接受 protocol=comfyui-http 的 notebook 连接 JSON，以及普通 HTTPS URL。地址禁止内嵌用户名密码、查询参数、片段和控制字符；允许安全的路径前缀；识别 /_moss/login 并还原 API 地址。远程仅 HTTPS；现有本地 HTTP 连接不变。
- JSON 可含 base_url、api_key、auth_header=Authorization、auth_scheme=Bearer、scope=current-colab-runtime、model_catalog=/_moss/models、可选 runtime_id；拒绝不支持的认证/协议，不把网页 notebook URL 当作生图接口。
- 密钥只在请求内存及 Windows 凭据存储中使用，不进入 SQLite、任务快照、工作流、日志或响应。导入失败不暴露输入。凭据写失败时不得留下可用的半配置；删除连接同步清理密钥。无密钥的公开 ComfyUI HTTPS 入口可使用。
- 通过统一连接/客户端工厂接入检测、环境路由、工作流资源检查、执行/恢复、图片上传下载及图库处理，保留注入测试工厂、SSH 指纹与本机限制。TLS 校验开启；HTTPS 请求禁止自动重定向，报错不展示上游回显的密钥。POST /prompt 不自动重试。
- HTTPS 网页入口使用独立登录页面（已识别的 MOSS 网关为 /_moss/login），明确由用户输入云端密钥；不声称浏览器已携带 Bearer，也不暴露带密钥 URL。SFTP 和 SSH 指纹仅适用于 SSH。
- 每次实际替换临时连接生成不含秘密的会话版本；同一目标的完全相同连接信息重复导入不产生新会话。新连接/地址/密钥/显式 runtime_id 改变使能力缓存失效并提高环境 epoch；保留资源映射作为待核验模板。导入版本不是云端运行时身份，旧 notebook 无 runtime_id 时必须诚实保留弱身份边界。
- 新 HTTP 任务冻结连接会话版本；恢复须在联网前核对，版本不匹配或缺失时明确拒绝，不查询新环境中的旧 prompt_id，不重提任务。历史 SSH/local 任务维持原行为，但把原档案改为 HTTPS 后不能绕过检查。正在执行的客户端继续使用已捕获的连接，不被后续导入改向。
- 不操作用户真实数据库、不启动或修改 Colab notebook、不发布或推送。实现与构建验证后，仅同步本任务变更回原项目，并保留原有未提交内容。

## 验证

使用有界协议模拟器/内存凭据存储核验导入、更新、保密、Bearer 全链路、重定向、连接失效与恢复拒绝；核验真实设置组件的导入、文件读取、更新和错误反馈；运行 V3 全部后端、前端测试、TypeScript 与生产构建，并在隔离测试数据上检查设置页面。真实 GPU 联调仍需有效运行时。
