# 提示词主编辑区与辅助设置 Sheet

用户已确认采用「主编辑区＋辅助设置 Sheet」，优先优化 2560×1440 最大化窗口，保留角色、作品与画师 tag 实时同步正向提示词。

## 设计

- 主区保留标题、撤销/重做、保存、正向与负向提示词、最近修改；输入区按剩余高度伸缩。桌面主编辑区不再依靠外层滚动展示辅助工具。
- 紧凑入口显示角色与画师、画面设计、分层要求、固定片段、中英对照；有选择时显示数量，主区仍显示 tag 实际同步状态和当前画师串摘要。
- 辅助设置从右侧打开原生模态 dialog 样式的 Sheet：宽屏宽 760px、窄屏接近全宽；固定标题/页签/返回按钮，仅正文滚动。2K 下主提示词仍可见。
- 五个页签的内容始终挂载，关闭与切换页签保留局部输入；以 workspace id 为 key 切换会话时重建辅助状态。
- 原有 edit/layer/editArtists/chooseArtistPreset 回调继续负责修改，角色、作品、画师增删不引入 LLM 或额外保存流程。
- 原生 dialog 处理模态焦点与背景不可交互；打开聚焦关闭按钮，关闭恢复入口焦点，支持 Esc、背景点击、页签方向键。补全候选优先消费第一次 Esc，输入法组字时不关闭抽屉。
- 不安装依赖，不修改后端、云端、模型、出图参数或已有草稿。

## 方案比较

1. 仅隐藏滚动条：无法减少滚动距离，舍弃。
2. 整个提示词移入抽屉：频繁编辑多一步操作，舍弃。
3. 主编辑区＋辅助设置 Sheet：用户已选择；保持常用编辑可见，集中低频辅助设置。

## 验收

- 2560×1440、1920×1080 与窄屏实测，无主区辅助项造成的滚动；长提示词自身可滚动，输入和操作不被截断。
- 抽屉关闭/重开和切换页签保留未完成输入，关闭后背景滚动锁解除。
- 角色/作品/手动画师/推荐画师增删仍同步正文，生成请求沿用保存后的精确提示词。
- 前端测试、类型检查、生产构建通过；对当前运行项目按文件校验备份后同步。
