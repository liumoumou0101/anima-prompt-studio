# MOSS 中文多画风工作台第一版

用户于 2026-10-27 确认方向并授权“按这个方向做一版看看”：支持原文直接出图、只整理润色、创意扩写；允许适当补充，但不改变明确内容。沿用已批准的 Colab 第二阶段，补上本次讨论确定的提示词辅助。

## 目标与选择

MOSS 用于二次元、洛可可、厚涂、平涂、宫廷肖像二次元和真人等画风及其组合。中文从输入到生成保持可用，没有强制翻译环节。独立 `/moss` 工作台共用云端连接、运行实例核验、任务、历史和画廊。候选方案为在 ANIMA 工作台加入条件分支，或提供独立页面；采用独立页面，避免标签编译和英文规则影响中文自然语言体验。

## 首版行为

- `moss_image_sft_int8` 是独立 `moss` 家族，使用现有 Colab 的 INT8 模型、Qwen3.5 编码器和 Flux2 small VAE；明确的原生扁平 API 图，单阶段文生图，无云端扩写。
- 原文出图不调用 LLM。只整理润色仅改善表达与顺序，不增加可见内容；创意扩写可增加适量兼容细节，不改变主体、数量、身份、颜色、服饰、动作、左右关系、指定画风、构图与排除项。引号内图片文字逐字保留，新增内容可见。
- LLM 返回独立可编辑建议，原文始终保留；不会自动采用或提交。用户明确采用后可编辑并出图，也可一键使用原文。源文本或模式变更使旧响应和旧建议失效；错误保留草稿，不降级成英文。
- `POST /api/v3/moss/prompt-assist` 消费 `{source_text, negative_prompt?, mode: polish|expand}`；返回 `{positive, negative, changes: string[], warnings: string[], mode, engine}`。复用已配置 LLM 传输与密钥管理；不新增供应商、密钥或翻译服务。限制长度/响应格式，错误脱敏，引号文字缺失或负面被修改则拒绝结果。
- MOSS 页面只选择 MOSS 模型/兼容工作流，不继承 ANIMA 页面参数、LoRA、override 或会话草稿。参数采用独立基线 25 / 2.5 / er_sde / simple，1024×1024，宽高为 16 的倍数；以真实推理校验后说明适用范围。现有 ANIMA 页面只列 ANIMA 模型。
- 复用现有 generation intent 提交/确认/继续协议和幂等性，缺资源先提示，网络超时不自动重复提交；选择明确环境，继续任务须沿用同一 intent。
- 实际提交的正负文本、模型文件、采样参数和输出都进入既有运行快照与画廊。历史恢复、重试能识别 MOSS，不能落回 ANIMA 图。

## 验收

自动检查覆盖中文原文、两种 LLM 指令差异、引号文字保护、负面保留、故障脱敏、无自动采用/提交、晚响应、草稿隔离、尺寸与工作流绑定，回归 ANIMA 和共享运行/画廊流程。Colab 用隔离本地数据做真实中文两种画幅、不同画风、原文/润色/扩写对照和 ANIMA→MOSS→ANIMA 切换，记录参数、耗时、图片。显存不足时根据事实调整，不把未完成推理标成支持。

不扩到图生图、布局编辑器、MOSS LoRA、放大或安装包重打包。连接和认证沿用上阶段，保留用户 Drive 缓存与图像。同步原项目前做来源校验与备份，不覆盖用户新修改与数据库。
