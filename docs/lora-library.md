# 在 V3 工作台使用 LoRA

## 首次添加

1. 打开侧栏的 **LoRA 库**，点 **打开收件文件夹**。当前源码项目的默认目录是 `H:\soft\提示词工具2\loras\`。项目移到其他位置时，使用项目根目录下的 `loras\`。便携版默认使用程序旁边的 `loras\`。页面会显示实际目录。
2. 将下载好的 `.safetensors` 文件放进去。可以按画风或模型建子目录。等文件复制完成，再点 **扫描文件**。扫描只收录到本地库，重复文件按内容去重。改名、移动后重新扫描，会保留已有资料。
3. 点 **编辑资料**，把「待分类」改为作者标明的模型系列。如果文件只适用于某个底模，在 **限定底模** 中勾选它。留空表示整个系列的工作台都可以选择该文件。分类是你填写的适配范围，实际效果仍须在相应底模上生成图片确认。
4. 保存默认权重。作者提供了触发词时，每行填一项。之后添加到创作会带入这些默认值，每次创作可以单独调整。

## 在工作台生图

在 **工作台**（ANIMA）或 **MOSS 工作台** 打开 **生成参数 → LoRA → 从库中选择**，点击资源名称。选择执行环境后，工作台会开始准备已启用的文件。等到「当前环境已就绪」，即可生成。

如果显示「当前使用历史工作流快照」，直接在 **LoRA 区**点 **切换模板并编辑 LoRA**。ANIMA 和 MOSS 都支持这个入口，会保留当前提示词、种子和手动参数，历史图片与任务记录继续保留。MOSS 会将切换结果保存到当前创作，重新打开仍可继续编辑。没有兼容模板时，会在此处说明原因。

已选资源使用紧凑卡片，直接显示名称、开关、顺序按钮和模型权重。文本编码器权重、触发词编辑以及手动条目的文件信息在每张卡片的 **高级设置**中。MOSS 使用模型权重，不显示文本编码器权重。

- **多项叠加**　在支持叠加的内置基础工作流中，用 **上移／下移** 调整加载顺序。取消勾选可临时停用，保留这项的权重和位置。列表最多保留 16 项。使用自定义固定工作流时，加载数量和顺序由该工作流的插槽决定。
- **模型和权重**　ANIMA 支持分别调整模型权重和文本编码器权重，后者留空时跟随模型权重。MOSS 使用模型权重，请选择与当前 MOSS 底模匹配的文件。库中可先按 **SDXL / Illustrious** 分类保存，生图需等对应工作台和工作流接入。
- **触发词**　ANIMA 更新提示词时会参考启用项的触发词。直接使用当前提示词生图或使用 MOSS 原文直出时，点 **复制已启用的触发词**，将需要的词粘贴到正文。复制会合并相同触发词。
- **已有服务器文件**　如果文件已在服务器的 ComfyUI 中，且你想直接沿用它，可展开 **手动填写已有服务器文件**，填写实际文件名及权重。手动条目按服务器上的文件名匹配，需自行管理文件。要由工具准备 Drive 缓存，请从本地库添加。

## 更换或重新连接 Colab

启用库资源时，工具先检查当前 Colab。运行时已有文件就直接复用。运行时缺失而 Drive 有缓存，就从 Drive 恢复。两处都缺时，才从电脑上传、校验并保存缓存。同一运行时重复生图无需反复上传。文件内容变更会作为一个新版本重新识别。

重新启动 Colab 后，挂载原来的 Drive，启动项目配套的 ComfyUI 网关，并在 V3 设置中更新临时连接。打开原创作后，工作台会重新核验已启用项。原运行时的临时磁盘可能已经清空，Drive 缓存仍在时可直接恢复。心跳用于观察连接状态，Colab 仍可能断开或回收实例。

如果提示准备失败，先确认当前连接和 Drive 挂载，再点 **重试准备**。本地文件缺失时，已有 Drive 缓存仍可用于恢复。如果两处都没有，请把原文件放回收件文件夹并重新扫描。
