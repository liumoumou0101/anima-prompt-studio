# V3 已验证问题与修复顺序

本清单只记录已通过真实远程生成或人工操作复现的问题；它用于约束后续开发方向，避免把不稳定的 AI API 再次放回决定性主路径。

## P0：人工测试被阻断

| 问题 | 已观察行为 | 修复原则 | 状态 |
| --- | --- | --- | --- |
| 自然语言主路径依赖 API 拆解 | 慢、重复结果不一致、字段格式会随机失效 | 本地翻译与本地规则为主；API 仅可选增强 | 首轮已完成 |
| 工作台结果丢失 | 提交远程生成后跳转；返回时解析结果消失 | 原地提交、自动恢复、后续写入工作区库 | 已完成首轮前端恢复 |
| 解析耗时过长 | 单次常见 50–100 秒，配置超时 180 秒 | 主流程不等待 API；API 必须可取消、可超时、可降级 | 主流程已替换 |
| 解析失败即丢失工作 | `pose/action/lighting` 返回数组、枚举越界 | API 不得阻塞主路径；保留原文和上次成功候选 | 首轮已完成 |

## 固定修复路线

本路线受 [PROMPT_CORE_LESSONS_AND_BOUNDARIES.md](PROMPT_CORE_LESSONS_AND_BOUNDARIES.md) 约束。V2 本地翻译是可编辑的语义保底，不是结构权威；V2 `PromptPipeline` 也不整体回接。

1. `Scene Draft` 已支持原文证据、可编辑画面计划、事实分层、实体锚点、人工属性归属、首个 `wearing` 关系、明确排除、待确认建议、部分未命中和风险分层。当前版本冻结通用复杂关系扩展，只保留可验证的直接标签与显式关系。
2. 已完成翻译 prose baseline：无标签命中也会生成可追踪、可编辑的 Literal，不会返回 422 或擅自补标签。
3. 已完成第一版“确定映射 / 明确排除 / 待确认匹配 / 未命中”：自然语言否定在翻译前分流，广义“文字”排除透明展开，原文只被部分覆盖时会明确标记未解析；仍需从真实失败族扩展可靠的证据规则。
4. AI API 拆解不进入当前默认主路径；未来若重新开放，只能作为显式触发、可审查且失败不清空工作台的辅助能力。
5. 已完成标签与画师默认不自动写入提示词；用户可选择 1～20 位画师，以相同模型、参数和 Seed 分别形成对照任务。
6. 以固定 Seed、固定 Aesthetic v1.1 工作流重新建立二次元立绘和代表失败族回归集。
