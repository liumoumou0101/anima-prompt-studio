# 独立参考案例库与会话复用

日期：2026-09-11。用户授权继续离线开发；本轮没有连接云主机、调用 LLM 或创建 GPU 任务。

## 已实现

- 侧栏新增“参考案例”，独立路由 /references，与画廊、标签、工作流并列。工作台只保留入口、当前来源和解除来源操作。
- 案例支持图片副本、标题、来源地址、外部提示词、个人笔记、结构化创作要求与 LoRA。保留上传、手动编辑、提示词提取、辅助读图和内置样例能力；进入页面不会自动调用分析模型。
- 提供来源筛选、标题/个人笔记/外部提示词搜索和分页。更换筛选后不能继续使用旧游标。内置样例仍只按标题检索；自定义分类和批量归档留待案例规模扩大后完善。
- 画廊详情“存入参考案例库”保存独立图片副本，成功后可直接打开该案例。工作台结果收藏也提供详情链接。
- 画廊图片有可验证的 V3 生成记录时，优先记录原提示词、参数、模型与任务快照引用；普通图片保存可获得的元数据，明确标注缺少原始生成快照。原图删除后，案例图片副本仍可查看。
- 案例缩略图与原图接入既有 gallery 范围的 HttpOnly 图片会话认证入口，修复此前浏览器原生图片请求缺少认证而显示破图的问题。没有扩大 Cookie 的 API 路径范围。
- 案例使用共用的原图查看器。修改标题、笔记或要求后，需保存或显式重新加载，才能切换案例或开始新会话。

## 两种使用方式

1. **借用要求，新建会话**：选择风格、光影、构图或完整场景，复制相应要求及必需 LoRA，保留来源版本。新会话不自动带入原图参数，也不调用 LLM；后续由用户编译或继续创作。
2. **沿用生成条件，新建会话**：从服务端生成记录恢复正负提示词、模型、采样参数、精确种子、原任务 LoRA 与工作流快照引用。英文直出任务即使没有结构化要求，也会恢复独立保存的 LoRA 选择。提示词通过本地合同生成新编译令牌，不经过模型改写。

两种操作都创建独立工作台，不覆盖旧工作台或其浏览器草稿。从案例链接进入后，再手动切换/新建会话会清除旧的指定会话参数，避免刷新重新打开来源会话。

沿用生成条件时，模型与执行目标锁定；可以修改提示词和参数。提交时服务端使用受保护的 generation_source，客户端传入其他快照不能将它替换。若要切换模型/目标，需点击“解除原工作流快照，改用当前模板”。缺失任务快照不会静默退回最新模板。

## 边界

- 这是从案例开始一次新的创作，不承诺不同云环境或资源变化后像素级复现。工作流继续由 ComfyUI 执行，资源映射与可用性仍由现有解析和预检负责。
- 案例自身保存图像副本和历史参数；完整工作流依赖本机持久化生成记录，并非跨电脑独立打包。跨机器案例导入/导出、生成记录清理后的快照保留策略尚未实现。
- 当前画廊元数据索引最多 1000 张，超出索引范围的图片可能只能保存图像。没有从普通图片推断不存在的工作流快照。
- 自定义分类、批量案例管理、案例编辑跨页面自动草稿恢复尚未实现。这里验证的旧草稿保护针对会话工作台。
- 本地 ComfyUI 直连、云上联调、工作台主创作流程和画师推荐扩展属于后续阶段。
