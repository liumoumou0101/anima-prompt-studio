## 目标与范围

采用“官方模板 + 按服务器适配 + 用户自定义工作流”的统一架构。现有六份打包工作流作为第一批模板素材；云端导入作为补充入口。

最终目标：全新用户无需开发者数据库，即可安装发布包、连接符合依赖要求的服务器、完成检测并生成；无法生成时可以知道具体原因和下一步。

首版覆盖现有 ANIMA 模型、SSH 连接和已支持的生成类型。暂不建设在线模板市场，不自动安装节点、下载模型或修改云端服务，不承诺支持任意 ComfyUI 图。

## 设计约束

- 官方模板只读、版本化，随软件发布；不再依赖启动时向用户数据库追加固定 JSON。
- 服务器能力与文件映射按连接保存，不能把任意本地工作流与所有服务器直接组合为可用目标。
- 用户修改保存为自定义副本；模板升级不得覆盖用户内容。
- 一个统一解析服务供工作台、直接提示词、画廊再生成和批量任务使用。
- 推荐基线和实验模板显式分类，不依靠文件名前缀或列表顺序选默认项。
- 静态兼容性检查通过与真实生图成功分别记录。
- 下述 API 名称和数据对象是待实现设计，不表示当前已经存在。
