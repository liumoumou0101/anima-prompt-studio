## 研究与实现

依据 [ANIMA 作者说明](https://huggingface.co/circlestone-labs/Anima/blob/f7382c4/README.md)：模型支持标签与自然语言混合；普通 tag 小写、空格代替下划线，画师必须带 @；可使用角色和作品名。明确填写标签调用模型已有知识，不训练新知识，也不保证任意名称被识别。多人关系和外观仍需场景描述。

核对 [ComfyUI Anima tokenizer](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/text_encoders/anima.py) 及 [SDTokenizer 的括号解析](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/sd1_clip.py)：消歧括号在输出时转义，避免被解析为权重。

- 工作台 → 画面要求 → 手动角色、作品与画师 tag，三栏每行一个，允许本地词库外标签，无需 LoRA。
- 新字段为 subject.character_tags、subject.series_tags、style.manual_artist_tags，分别最多 32 项；支持去重、大小写/下划线整理，画师输入可带 @。单个 tag 不接受逗号或换行，不把多个标签当一项。
- 手动字段随工作台要求及草稿保存，场景参考的整组/风格复用沿用现有层复制逻辑。它们不在 LLM 可修改的 layer_updates 中，改主体描述或画风不会顺便清掉手动标签。
- LLM 编译后由服务端加入明确选择的标签，在最终正向框可见；PNG 提交沿用已有可见文本链路。画师推荐仍有原有 artists 字段，不需要重做关联数据。
- 编译结果保存受控标签记录，用于下次编译去重或移除不再选择的完整标签项。不会盲删自然语言句子中提到的人名，涉及角色关系的文字需用户复核。
- 直接手改正负提示词仍保持原文，不在生成提交时偷偷追加；固定标签在下一次 LLM 编译时重新按要求加入。更换角色请修改标签栏并重编译。
- 老会话新增空字段不会改变旧输入指纹，不使已编译提示词全部失效；保留旧数据和提交恢复语义。
