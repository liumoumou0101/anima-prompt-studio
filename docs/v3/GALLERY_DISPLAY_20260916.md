# 画廊显示与交互稳定性改进

日期：2026-09-16。基于 `a9b0eb8` 开发；本次为源码和本机 Web 构建更新，未重打安装包。

## 本轮行为

- 保留单击图片查看详情。桌面详情改为悬浮面板，不再给网格增加 430px 右内边距；打开、关闭和切换图片不改变网格宽度。增加上一张／下一张详情按钮。
- 卡片增加独立放大入口，文件名与选择控件在悬停或键盘聚焦时显示；触屏保留可见操作。统一排列来源、保留／淘汰和画师徽标，避免互相覆盖。
- 筛选默认折叠，筛选和任务面板使用浮层；已选筛选以可清除标签保留。精简标题、工具栏和常驻说明。
- 成功、进度及已有数据时的操作错误使用浮动提示，不向下推图片。任务面板关闭后，未完成任务仍继续轮询。
- 详情预览扩大，参数分组，文件来源折叠。底部突出再出图与保留，其余操作集中到更多菜单。
- 窄屏详情锁定背景滚动；先解除背景 inert 再恢复焦点。详情、原图和再出图弹窗共享可嵌套滚动锁，不重复补偿固定面板的宽度。
- 原图使用打开时的图片序列快照，通知消失或后台加入图片不会使正在浏览的原图跳回开头。修复 Lightbox 禁用按钮浅色方块。
- 比较视图限制在可用高度内，完整显示原图、文件名和生成参数；支持 Escape、焦点约束和焦点恢复。3–4 张使用 2×2，小屏／矮窗在比较区域内滚动。
- 退出多选或清除已选项后回到普通浏览。打开详情／原图／比较期间暂停继续追加卡片。

桌面浮层会暂时遮住右侧部分图片，以换取网格位置稳定；可用详情中的前后按钮继续浏览，或关闭面板恢复全幅图库。尚未重做服务端分页，现有 1000 张索引上限保持不变。

- 前端全量：36 个文件、226 项测试通过。命令：`npm exec --yes --package=node@22 -- node node_modules/vitest/vitest.mjs run --maxWorkers=2`。默认并发首次全量运行出现一个无关场景设计测试的 5 秒超时，限制并发后的全量通过。
- 1440×900：连续五次开关详情，前四张卡片的位置、宽高、渲染数量与 `scrollY` 均完全一致。第一张图片起点从约 508px 提前到约 302px。
- 桌面页面中段：`scrollY=900` 打开／关闭详情后保持 900，焦点回到触发图片。
- 390×844：在详情内滚动到底并继续滚动，背景 `scrollY` 保持 900；关闭后卡片矩形和滚动位置恢复原值，焦点正确恢复。
