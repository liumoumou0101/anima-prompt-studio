# 工作流模板库与执行环境管理

日期：2026-09-11。本轮完成离线开发与本地验证，没有连接云显卡或提交生图。

## 使用入口

侧栏新增“工作流”（`/workflows`）。设置页负责连接、认证和应用偏好，并提供携带当前环境 ID 的工作流资源入口。

“本地模板”显示官方模板及用户副本，可以搜索、按模型筛选、查看内容版本、声明文件、节点依赖和来源。启停模板作用于模板库；映射按执行环境独立保存。离线、没有任何服务器配置时也可查看和导入模板。

“编辑副本 / 模型关联”导出当前模板到编辑区；解析后可编辑名称、备注和兼容模型，确认后保存为独立用户模板。原模板不被覆盖，也不继承任何环境的文件映射。模型关联是兼容声明，不会自动替换图内权重。支持下载当前模板、恢复已归档内置版本为用户副本；用户版本通过独立副本及来源版本串联。

支持本工具导出格式和受限的 ComfyUI API JSON 自动解析。自动识别没有兼容模型时可以先预览，再人工勾选关联。复杂图仍须提供明确 bindings，ComfyUI 编辑器格式不自动转换。明确冲突的 Aesthetic 权重版本不能通过修改关联绕过验证。

“执行环境与资源”选择已保存的 SSH 环境，显示本地缓存的检测结果。打开页面和切换环境不启动远端检测；点击“检测并刷新服务器能力”才会连接。映射展示模板声明的原文件与当前环境实际文件，依赖过期时禁止保存；资源名称不匹配时不会自动猜选替代。切换环境清空临时密码和私钥口令，重置映射草稿。已有取消检测、脱敏诊断和云端 JSON 读取入口保留；云端文件只作为可选导入来源。

本地 ComfyUI 直连仍未实现，页面明确说明后续接入，没有放置无法使用的本地执行选项。

## 实现与版本边界

- 新增 `GET /api/v3/workflows/catalog`：离线模板列表，不需要选择服务器。
- 新增 `POST /api/v3/workflows/preview`：验证和解析，不保存模板。写入继续使用既有 import 接口。
- 模板导出/预览增加独立 `source` 信息，保存准确的源 ID 与源内容版本。修复清空导出路径信息导致来源版本号漂移的问题；新副本自身仍有独立内容版本。来源信息是导入声明，不是签名验证。
- 环境报告增加 `template_value` 与 `node_type`；既有映射仍按环境、模板、版本与连接指纹校验。没有迁移或更改现有用户映射。
- 现有 V3 提交保留实际 `workflow_snapshot`，LoRA/资源解析在快照 `runtime_assets.binding_template_revision` 和 resolution 中保留模板版本。继续向 ComfyUI 提交完整 API graph；不依赖远端保存同名工作流。本轮没有修改生成编译算法或模型配方。

主要实现：`web/src/pages/WorkflowsPage.tsx`、`web/src/components/WorkflowManager.tsx`、`src/anima_prompt_studio_v3/api/workflows.py`、`src/anima_prompt_studio_v3/runtime/workflow_catalog.py`。
