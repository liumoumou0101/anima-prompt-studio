| 部分 | 代码事实 | 后续处理 |
| --- | --- | --- |

| 自动导入 | `runtime/workflow_import.py` 自动绑定只覆盖单个 KSampler、直接 CLIPTextEncode、唯一模型加载节点、EmptyLatentImage、SaveImage 等受限结构；LoRA 自动发现只覆盖 LoraLoader | 不能宣称任意图都能自动识别；复杂图须显式提供 bindings 并人工确认 |
| 图内参数 | `core/workflow_compiler.py` 仍存在 HIRES_FIX 特殊分支：第二阶段种子递增、放大比例缺省 1.5 等 | 后续变为模板明确声明的能力；不能一概宣称前台只替换两个提示词字段 |
| 文件与画廊 | `adapters/v2/gallery.py` 仍复用旧索引、缩略图、回收站文件工具；再生成已走 V3，图像超分仍是独立管理器 | 保留可靠文件工具；按职责迁移，避免为了消除 V2 字样重写稳定逻辑 |
| 自然语言 | `api/server.py` 仍创建 `build_v2_intent_parser` 适配器 | 作为实际执行依赖单独记录，不与生图队列迁移混为一谈 |
| 本地翻译模型 | `api/server.py` 仍连接 `build_v2_local_translation_adapter()`；有资源和运行时则选择 LazyLocalMarianEngine，否则 BuiltinOfflineEngine | “已完全移除本地翻译模型”目前不成立。模型延迟加载，不能等同于启动即占满内存。下一阶段应明确移除 Marian 的产品入口与运行接线，保留标签字典翻译能力 |

NAG 与 LayerReplay 是工作流内的模型补丁节点，不能统一称为 LoRA，也不是提示词工程。是否启用应归属具体模板能力及模型配方。已有 52 张云端质量测试见 [质量矩阵](QUALITY_MATRIX_20260911.md)；本轮没有新增画质结论。旧 Base+LoRA Turbo/DMDX 与完整 Turbo 1.0 的覆盖范围仍需区分。

## 本轮已完成

- 画廊增加明确的多选模式；Shift 按当前筛选和排序跨日期组连续选择，单击可取消单张。修改筛选、排序或视图后清除旧选择，避免操作隐藏结果。
- 空白处可拖动框选，多选模式下可从图片上开始；Ctrl/⌘/Shift 可追加框选，Esc 撤销当前拖动，窗口边缘拖动可滚动。框选只命中已渲染图片；触屏保留滚动和点选。
- 全选作用于当前已索引的筛选结果，包括尚未展示的条目；界面明确标注索引最多 1000 张。未实现无限索引分页，不等于全选磁盘所有图片。
- 批量回收、永久删除、恢复按服务端成功回执更新，仅保留失败条目的选择，便于重试。恢复新增 `restored_trash_paths`，同名改名恢复时也能识别原回收站条目。
- 画廊与会话工作台生成结果复用 `components/ImagePreview.tsx`，支持翻页、缩放、图片信息和关闭；工作台点击结果不再默认打开原图网页。原图新标签页链接作为信息面板中的次级入口保留。
- 工作台预览按图片路径读取历史画廊参数；找不到时明确提示，不用当前草稿参数冒充旧图参数。大种子仍以字符串展示。
- 修复实际窄窗口验收发现的查看器横向滚动偏移，以及详情抽屉在预览打开时抢占 Escape/Tab 的问题。

## 下一阶段顺序与验收目标

1. **工作流与环境管理。** 本地保存模板及版本；模型适配关系允许自动建议和人工确认；本地/云端环境各有资源映射及预检结果。验收：同一模板切换环境后明确指出缺少的节点/权重，替换资源不能静默发生，生成记录保留实际图及模板版本。无需远端保存同名工作流。
2. **参考案例库独立页面。** 与画廊、标签并列，保存参考图、提示词、参数、来源、笔记和分类；画廊能转入。区分“借用创作要求”和“复用完整生成条件”。验收：导入多案例可检索，回到工作台不会覆盖未保存草稿。
3. **工作台创作流程。** 明确当前要求、已编译提示词、此次参数与任务结果的关系；支持基于结果继续调整、对比与复用。保持提示词创作工具定位，不直接照搬聊天软件。
4. **画师推荐扩展。** 三种推荐模式移到工作台可即时切换，按需运行、保留已有选择；同时明确移除本地 Marian 模型接线。用实际启动/空闲/推荐时内存测量验证资源开销，不凭代码体积估计。
5. **本地 ComfyUI 接口。** 在环境抽象稳定后接入，与云端复用模板、预检、队列和结果存档；本地推理资源开销归 ComfyUI，前台仍须控制缩略图、原图与索引占用。
