# 本地 ComfyUI 环境接入（2026-09-11）

续接任务「测试连接」。此前最后讨论明确本地 ComfyUI 通过本机地址直接连接，沿用现有生成管线。本轮实现该阶段，不修改模型配方，不制作安装包。

## 实现

- 设置页新增“本地 ComfyUI”连接类型，支持 127.0.0.1、localhost、::1 与自定义端口；SSH 连接为旧记录默认类型。连接信息仍保存在现有数据库，无需迁移用户数据。
- 本地连接不创建 SSH 隧道、不读取 SSH 密码、不要求主机指纹。`host_fingerprint_confirmed` 保持真实含义，新增 `connection_ready` 表示连接具备执行前提；资源是否齐全仍由工作流预检决定。
- 复用 V3 提交、执行、恢复、参数编译、能力检测、资源映射、LoRA 目录和结果归档。画廊放大通过注入本地连接工厂沿用现有处理器，画廊再生成继续走 V3 提交服务。
- “打开 ComfyUI 网页”使用所选本机实际地址；每次打开本地入口都会验证服务。SSH 仍使用原有主机验证和隧道。环境地址更改后不复用旧入口；未保存的连接修改会禁用测试和打开按钮。
- 本地环境不显示云端 SFTP 文件导入；本地工作流继续用文件导入或粘贴 JSON。服务端也明确拒绝对本地环境执行 SFTP 读取。
- 环境指纹包含本地连接类型和端口，修改后能力与映射必须重新确认。SSH 指纹哈希保留旧算法结果，避免仅新增字段就使既有冻结提交失效。
- 修复实际浏览器发现的快速检测竞态：先读取检测状态，再读取能力报告，避免把旧能力结果与“已完成”状态组合返回，导致前台不再轮询。

## 验证

- 本地 HTTP 协议模拟器覆盖环境检查、节点信息、工作流提交、历史读取与文件下载；验证正负提示词、生成结果归档，以及恢复只读取原任务、不重复提交。模拟文件不是实际 GPU 成图。
- API 验证本地配置创建、连接测试和异步资源检测均不要求 SSH；拒绝本地 SSH 指纹操作。回归覆盖非本机地址拒绝、SSH 旧快照哈希兼容、地址更改失效与快速检测竞态。
- 浏览器使用独立数据库，实际完成创建本地连接、保存、自定义端口测试、打开网页入口、进入环境页并检测。模拟器无节点，前台如实显示缺少节点；修复后无需刷新即可显示最新检测结果。
- 前端全套 113 项通过，TypeScript 与生产构建通过。使用已验证的 Node 24.19.0；系统 Node 24.11.1 的原生构建退出问题仍存在，未改变系统环境。
- V3 后端最终全量 489 项通过；本地连接与维护入口专项 11 项复验通过，本轮也通过既有画廊放大及工作流相关回归。

## 使用与边界

重启开发程序，在设置中新建连接，类型选择“本地 ComfyUI”，填写本机端口并保存，点击“测试本地连接”。在工作流页面选择这个环境，检测并确认模型、VAE、编码器、LoRA 和节点资源，再从工作台选择对应环境生成。

本轮没有安装或启动真实 ComfyUI，没有调用外部 LLM、连接云主机或执行真实 GPU 生图。实际硬件、用户本机权重和真实放大仍需后续联调，不能将协议测试当作画质验收。当前只支持本机 HTTP 直连；局域网、远程 HTTPS 和额外认证不在本轮范围。

隔离材料位于 `.local/local-comfy-20260911/`，包含协议模拟服务、独立数据库与全量测试日志。验收服务通过 stop 标记停止，测试页面关闭；原开发服务未动，需正常重启以加载新后端。源码未提交、推送或打包。
