# 通用改写要求保留优化 · 2026-09-26

## 本轮范围

用户认可现有“适度扩写”的视觉改善，要求继续做通用优化；随后明确不需要独立 LLM 审核，并接受当前便宜、未开启思考的模型存在能力边界。本轮目标是减少输入歧义与跨层遗漏，保留已经有效的创作空间，不追求八例全部完美。

## 已落地

- 新增 `core/rewrite_sources.py`：服务端从实际工作台输入整理 `preservation_sources`，逐项保留原始字段值，不翻译、不推断隐含画面事实。
- `required` 列出当前必须保留的内容；`previous_context` 收纳兼容的历史信息；`superseded` 标明已清除或替换的控件、已移除的手工标签。
- 用户提供当前可见英文时，它是未锁定内容的权威起点，旧未锁正文降为历史上下文。锁定层、当前控件、手工标签、画师和字面锁仍保留优先级。
- 明确要求模型核对所有非空层：主体属性不能代替主体名词与人数，构图和画风不能因为位于其他层而漏写；首次描述与后续修改应同步相关要求。
- 已删除独立审核的模块、运行时开关、额外调用和专用测试。正常成功改写仍只有一次 LLM 调用；异常格式仍沿用原来的一次格式修复。模型、思考设置、采样与生成流程没有修改。
- 指导版本更新为 `anima-scene-guidance/2`，历史 LLM 编译可显式刷新；手写内容不会被自动改写。

这些规则按输入来源工作，没有具体题材分支、固定夜景模板或中英关键词替换表。来源清单本身不构成任意自然语言的完整性证明。

- 来源分类与真实请求边界新增 10 项测试，覆盖跨层输入、可见英文优先、锁定内容、控件和标签失效来源、原始字段保持、单次调用及同步入口。

### 固定八例真实文本检查

使用现有 `opencode_go / mimo-v2.5-pro` 配置，通过真实 `ConversationService.turn` 与隔离数据库执行。每例只调用一次，没有对语义结果重抽择优，没有图片生成。

完整输入、模型返回、最终正负向、持久化要求、代码哈希及错误记录均在 [source-guided.json](../../.local/prompt-guidance-general-20260926/source-guided.json)。对照为原 [baseline-review.md](../../.local/prompt-guidance-general-20260926/baseline-review.md)。

| 场景 | 本轮文字结果 |
| --- | --- |
| 夜景忠实 | 上游 `incomplete_response`，未产出，不能评价语义。 |
| 平涂侧脸 | 补回 `1girl`；全身、侧脸望远、纯色色块、简单明暗及非写实质感保留。微风和暖光仍有适度扩写。 |
| 室内静物 | 左右杯壶、合书、无人、左窗柔光、中景平视及水彩保留；新增受光与木纹细节。 |
| 图书馆 | 中央拱门、两侧各三窗、空街、整栋正面对称、阴天及钢笔淡彩保留；新增细节与此例风格兼容。 |

结果为 5 例未见明确硬约束问题，1 例局部修改越界，1 例中文要求未同步，1 例上游未完整返回。7 个完成样本均保存、恢复一致；存储一致不等于语义完全正确。

这是主代理与独立代理逐条文字检查的单轮观察，不是稳定通过率或用户视觉验收。没有因两项剩余语义问题继续追加规则、调用或场景补丁。

## 审核实验为何撤回

此前尝试的独立模型审核同时出现漏报和误报，例如漏掉构图、把已有红围巾报成缺失、错误要求恢复旧蓝外套。它不能可靠承担默认保存门槛，也可能引导修复破坏正确内容，用户确认后已从产品代码移除。

失败与中间结果保留为研究记录：[首轮审核](../../.local/prompt-guidance-general-20260926/candidate-reviewed.json)、[修订审核](../../.local/prompt-guidance-general-20260926/candidate-refined.json)、[固定旧样本审核](../../.local/prompt-guidance-general-20260926/frozen-review.json)。这些均不属于最终运行流程。
