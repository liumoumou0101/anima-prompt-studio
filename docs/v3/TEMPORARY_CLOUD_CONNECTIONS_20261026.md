# 临时云端 ComfyUI 连接（2026-10-26）

V3 设置页可导入临时 HTTPS ComfyUI API 地址和访问密钥，也可读取 `moss_connection.json`。新建连接和更新已有临时连接均不会自动执行生图请求。原有本机直连和 SSH 连接继续使用原入口。

## 从哪里取得连接信息

在云端 notebook 完成启动后，复制最后一个输出单元格提供的 **HTTPS API 地址**，并准备原始访问密钥。Colab 笔记本分享网址不是 ComfyUI API 地址。访问密钥输入框只填写原始值，不加 `Bearer ` 前缀。公开的 HTTPS ComfyUI API 可以不填密钥。

如果 notebook 提供 `moss_connection.json`，可下载后选择文件，或将文件内容粘贴到“连接信息”。JSON 需要声明 `protocol: "comfyui-http"` 和 `base_url`；可携带 `api_key`、`auth_header: "Authorization"`、`auth_scheme: "Bearer"`、`scope: "current-colab-runtime"`、`model_catalog: "/_moss/models"` 及 `runtime_id`。不要自行填入不支持的协议或认证方案。文件最大 64 KiB，应用仅读取文本，不执行内容。远程连接要求 HTTPS；禁止 URL 内嵌用户名/密码、查询参数及片段。

## 新建与更新

1. 打开“设置”→“导入临时连接”，选择“新建连接”。
2. 填写连接名称，粘贴 API 地址及可选密钥，或选择 JSON 文件。
3. 点击“导入并保存”。成功后自动选中保存的连接；保存不等于已连通，请点击“测试临时连接”。
4. 打开“管理此环境的工作流资源”，检测并核对模型、节点和文件映射后，再进行生成。

云端重启、域名变化或密钥轮换后，先选中原来的临时 HTTPS 连接，再打开导入面板并选择“更新当前临时连接”。输入**完整的新连接信息**，含仍需使用的密钥（或含密钥的 JSON）。使用普通地址或不含密钥的 JSON 时，将访问密钥留空会清除原密钥，适用于改用公开 API；JSON 自带非空密钥时使用其中的密钥。只修改名称或启用状态时，使用下面的“保存连接”，该操作不会修改 API 地址或密钥。

更新保留逻辑连接 ID、模型映射及工作流偏好。地址、密钥或显式运行时标识改变，会建立新的连接会话并使旧资源检测结果失效；完全相同的重复导入不会另换会话。保留的映射只可作为待核验模板，不代表新运行时已拥有相同模型。

图库放大会在查看处理状态和提交新任务时读取当前已导入的 HTTPS 连接；首次导入或替换连接后无需重启应用。替换后才提交的任务使用新地址、会话和密钥，已接受的排队及执行中任务保留各自捕获的连接。设置列表与连接测试结果显示完整的 HTTPS API 地址，包含路径前缀。

导入失败不会替换当前选中的配置；修正后可重试。成功、取消或离开页面时，导入框中的原始 JSON 和密钥会被清空；不会写入 localStorage。密钥保存在 Windows 凭据管理器，不能通过配置数据库或响应取回。删除连接会同步清理保存的密钥，但保留生成记录、图片与远端主机内容。

## API 与网页登录入口

API 请求使用保存的 Bearer 密钥；浏览器网页访问单独登录。已识别的 MOSS 网关可提供 `/_moss/login` 入口，用户仍需在浏览器中手动输入密钥，应用不会生成带密钥 URL，也不会声称浏览器已自动完成认证。

只粘贴普通 HTTPS API 地址时，应用可能无法识别网页登录入口。此时仍可测试 API；网页入口请从云端打开。设置页不会将未知网关替换为 SSH 的本机 `18188` 地址，也不会猜测普通 API 地址就是可登录网页。

## 临时身份与恢复边界

导入产生的会话版本只能证明本地连接配置是否被替换，不能独立证明云端运行时身份。未提供 `runtime_id` 的 notebook 属于弱身份场景：同一个域名和密钥可能已经指向重启后的环境，应重新导入并检测资源，不能保证自动识别所有运行时变化。

新 HTTP 任务固定创建时的连接会话。连接已被替换或会话快照缺失时，旧任务在联网前拒绝恢复；不会拿旧 `prompt_id` 查询新环境，也不会自动重提交任务。需要用户检查当前连接和资源后，自行发起新的生成。已经执行中的客户端继续使用其捕获的连接，不因后续导入自动改向。

这项功能只增加连接能力，**不增加 MOSS 模型或工作流支持**。是否能生成某种模型，仍取决于云端安装的模型、节点、工作流及当前工作流资源校验结果。
