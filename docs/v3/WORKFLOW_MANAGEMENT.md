# 工作流管理：使用与维护

状态：2026-09-06 实施版。模板随程序发布，不需要开发者的 SQLite 数据库。

## 新用户操作

1. 设置中保存 SSH 连接，核对并确认主机指纹。密码沿用系统凭据存储。
2. 打开该连接下的“管理工作流”，点击“检测并刷新服务器能力”。“测试完整连接”只验证连接，不代表模型依赖已就绪。
3. 展开对应模型的基线模板。缺少节点时在服务器自行安装；资产名称不同时，从该服务器返回的文件列表选择并保存映射。
4. 返回工作台或直接提示词页面选择模型和就绪目标，提交生成。实验模板不会被自动选作替补。

能力缓存有效期 15 分钟。工作台和直接提示词提交时，未检测、过期或上次连接失败会自动刷新能力，通过后继续提交，无须先到设置手工检测。缺失节点/资产及映射失效仍会阻止提交；连接指纹未确认也不会自动信任。检测只读，不安装插件、不下载权重、不修改云端服务。

工作台、直接提示词及排队/批量提交通过同一目标解析器。画廊“再生成”使用相同就绪基线解析并保存图快照。专用分块放大保留原配置及执行前预检，尚未统一到新目录；这是 Todo 全类型覆盖的剩余项。

“依赖就绪”说明节点及输入与快照匹配，不证明显存足够、权重完整或生图成功；文件名不能证明权重身份。运行记录和下载产物才是实际生图证据，不会将一次成功泛化为所有尺寸和实验图已验证。

## 自定义与跨电脑迁移

点击“导出 / 创建副本”，在 JSON 编辑区修改 `profile.display_name`、图或 `bindings`，然后校验并导入。导入始终创建独立 `user:` ID，不覆盖官方或原用户记录。修改后可禁用旧项，导出新副本到另一台电脑。

支持本地文件、粘贴和指定绝对路径的云端 JSON 读取预览，上限 2 MB。云端读取不自动导入，也不遍历整个服务器。普通 API 图仅对单 KSampler、直接 CLIPTextEncode、EmptyLatentImage、单模型加载器及 SaveImage 的明确结构推断绑定。复杂图需提供软件配置格式和完整绑定；不转换任意编辑器图。绑定通过 JSON 编辑，不是可视化节点编辑器。

导出包含实际节点输入，可能含私人提示词，分享前务必检查。报错优先使用“生成脱敏诊断”，预览后下载，其白名单不含地址、凭据、节点文本和文件路径。

## 数据保护与升级

- 启动不再往用户表追加六份固定模板。资源模板与用户记录分开读取；同 ID 用户修改保留，官方必要时以 `official:` ID 避让。
- 一次性所有权迁移先使用 SQLite 一致性备份创建 `backups/workflow-catalog-*.db`，再事务写入 schema 标记。失败不完成标记，重复启动可重试。
- 只认领内容哈希完全一致的旧官方记录；不明来源保留为用户数据。
- 官方内容版本存档保存在本地 settings，目前不自动清理，可恢复为用户副本。
- 映射绑定服务器配置指纹和模板哈希。版本变化保守地要求重新确认，不自动猜测兼容性；当前没有逐节点升级 diff。
- 入队保存模板/映射快照，执行再次验证最终图，记录实际发送图及产物。产物入库后才发布 completed。
- 手工恢复备份须先退出软件，保留现有数据库及其 WAL/SHM 文件副本，再替换为一致性备份，不能运行时覆盖。

## 模板贡献

修改 `configs/workflow_catalog.json` 和 `configs/workflow_profiles/`，同时维护稳定 ID、版本、模型声明、基线/实验级别、绑定、资产输入及空库/图结构/渲染测试。新增基线或依赖变化须补实机验收，不能只提交个人数据库。宽高由运行时绑定写入，无需编辑器 ResolutionSelector 插件。

禁止嵌入私人地址、令牌、密钥和提示词。许可证声明仅覆盖本项目维护的集成图定义（GPL-3.0-only），不覆盖第三方节点代码和模型权重；它们不随模板分发，各自许可仍需遵守。来源或分发权不清楚的外部模板不应加入官方清单。

## 排障

- 未检测 / 需重新检测：保存连接后刷新能力，不能只测试连接。
- 缺少节点：安装所列节点并重启 ComfyUI，再检测。
- 资产或参数不匹配：核对权重和枚举选项，保存当前服务器的映射。
- 映射需确认：模板或连接变更，重新检测后保存映射，或明确确认默认文件。
- 检测失败：检查指纹、认证及服务。旧快照保留但不再就绪。取消阻止后续检测结果发布，底层连接通过有界超时退出。
- 无官方模板：按支持表导入兼容图，不会从其他模型借用工作流。

## 验收工具

`v3/tools/validate_workflow_installation.py` 是显式、会消耗 GPU 的验收工具：复制选定连接到临时空工作流数据库，从系统凭据存储认证，运行三个官方基线并核对下载，生成 `acceptance.json`。不导入私人工作流，不开机，不安装依赖。发布还须前后端测试、生产编译及实际构建产物资源检查。
