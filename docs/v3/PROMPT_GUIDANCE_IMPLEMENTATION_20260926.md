## 实现

- `core/prompt_guidance.py` 集中管理忠实/扩写任务、混合表达规则、画面设计原则和模型指导版本。
- `api/conversation.py` 从工作台保存的 `model_profile` 读取注册配置，将 `model_guidance` 与所选模式的 `rewrite_goal` 送入真实改写请求。历史记录缺模型字段时沿用现有默认值；未知模型仅用通用描述原则，不根据名称猜测偏好。
- 忠实模式只组织明确事实。适度扩写可以补充合适的受光、姿态、空间和材质描述，必须保留明确要求、手改英文、锁定内容、人数和属性归属。局部修改仍只改指定部分。
- 标签用于稳定概念，连贯英文用于动作、光照和空间关系；不设机械字数门槛。英文正负向与中文改动说明各司其职。
- 扩写新增内容进入正向及改动说明，不写入只读场景控件，也不把创作补充冒充用户原始要求。沿用现有更新、历史及撤销流程。
- `core/scene_design.py` 消除“所有未指定构图都禁止补充”与扩写目标的冲突；明确控件值仍只由用户操作确定。
- `CompiledPrompt.guidance_version` 记录规则版本。旧 LLM 编译内容可显式刷新，加载时不自动改写原文；用户手写内容不因规则版本变化而失效。输入指纹中已有的模型区分继续生效。
- 英文直出、要求同步、生成参数、模型权重、LoRA 和负向默认值没有改写。

## 模型指导依据

使用 [官方模型卡的固定快照](https://huggingface.co/circlestone-labs/Anima/blob/f973fc41ec7545364ac9776c2440285f43ff2a30/README.md)，核对日期为 2026-09-26。

模型支持标签与自然语言混合。Aesthetic 的作者说明建议正负向避免添加 `score_*`，质量前缀可省略；不能把该限制直接套用到 Turbo。代码从现有配置提供可选前缀，不自动添加质量词，不删除用户已审核或固定的字面内容。社区模型没有经过核实的专属指导时只使用通用原则。

### 真实文本模型检查

使用当前配置的 `mimo-v2.5-pro`，通过实际 `ConversationService.turn`，在隔离的本地工作台数据库中验证。没有连接云 GPU 或生成图片，没有修改用户已有会话及模型配置。

保留所有轮次，包括失败的语义样本：

- [初版六场景](../../.local/prompt-guidance-20260926/text-validation.json)：能保留大部分事实，但扩写几乎只重排标签。
- [加强系统指导后的六场景](../../.local/prompt-guidance-20260926/text-validation-refined.json)：仍存在空 delta 时不扩写，以及说明与实际正向不完全对应的问题。
- [两次定位对照](../../.local/prompt-guidance-20260926/diagnostic.json)：明确扩写任务后会增加具体画面内容；只用极简设计指令则会过度加服装、道具、画风和负向，说明保真边界仍有必要。
- [加入模式任务后的检查](../../.local/prompt-guidance-20260926/text-validation-goal.json)：出现实质扩写，同时发现一次中文正向输出，随后明确英文输出和新增对象的边界。
- [六场景复核](../../.local/prompt-guidance-20260926/text-validation-final.json)：扩写改善，但仍出现遗漏全身或画风、为锁定主体补属性的问题，随后加强跨层事实核对与锁层约束。
- [完整性复核](../../.local/prompt-guidance-20260926/text-validation-coverage.json)：夜景保留全身并补充受光；双人例子保留人数、左右归属、全身和动漫风格。平涂例子仍加了渐变，继续明确纯色色块的边界。
- [最终平涂复核](../../.local/prompt-guidance-20260926/text-validation-flat.json)：保留侧脸、看远方、不看观众、全身、纯色色块和简单明暗，新增光线照到校服受光面及地面长影。

最近样本中的实际改进示例：

```text
1girl, black hair, school uniform, standing, full body, night, starry sky,
grass field, starlight softly illuminating the face and uniform,
gentle breeze moving the skirt and hair, subtle grass texture underfoot
```

剪影样本保留黑色背影与脸不可见；局部修改样本只增加衣领受月光照明，保留原英文其他内容及 `text, watermark` 负向。样本均在保存后重新读取核对。

这些是迭代中的小规模定性检查，不是稳定通过率评估。模型仍可能漏项或给出不完整的改动说明，代码没有宣称已能完全验证任意自然语言语义。没有实际生图，因此不宣称画质提升已经得到图片验证。

## 使用与后续

启动更新后的源码版本，在现有工作台选择“适度扩写”再更新提示词。已明确的剪影、背影、侧面、画风等要求继续写在画面要求或当前提示词中；“忠实还原”和“英文直出”保留各自用途。

后续先以固定模型、参数与种子的少量图像对照验证收益，再决定是否接入经过筛选的参考案例。不能把本次单一夜景组合写成所有场景的固定模板。
