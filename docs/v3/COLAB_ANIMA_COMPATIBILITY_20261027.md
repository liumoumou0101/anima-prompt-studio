## 开始使用

1. 关闭旧的 V3 进程，重新运行项目根目录的 `启动 ANIMA V3.cmd`。本轮更新源码及网页构建，未重新生成安装包或便携 EXE。
2. 打开原 [Colab 笔记本](https://colab.research.google.com/drive/1mdB_uIc_xcMOxBbUy-D4fTVm5y8YqQBv)。准备单元可在 `MODEL_ID` 选择具体 ANIMA；只准备该模型及共用编码器、VAE。需要切换多款时，选择“按模型组”及“仅 ANIMA”。原有模型组选项保留。
3. 运行准备、启动、云端 API 单元。在 Colab 左侧文件列表下载本次 `/content/moss_connection.json`，然后到本地设置页“导入临时连接”导入。JSON 会携带本次实例标识；访问密钥单独保存在 Windows 凭据管理器。
4. 工作台选好模型和基础工作流，在“执行环境”固定选择该 Colab，再打开“参数”页。点击“刷新云端目录”，核对文件后点击“应用当前工作流文件映射”。需要使用云端推荐值时，先看改动预览，再点击“应用云端建议参数”。
5. 首次生成若提示资源身份待确认，核对文件映射后点击“确认当前环境资源映射”，再“重新检查”。该操作继续原生成意图，不会重复提交图片。

目录刷新不改用户参数。“应用云端建议参数”只调整步数、CFG、采样器和调度器；手动尺寸、Seed、张数和提示词保持不变。目录中的“文件齐全”表示文件检查结果，出图是否成功由实际任务记录。

## 更换云端环境

地址、密钥或实例变化后，在设置中选中原连接，使用“导入临时连接 → 更新当前临时连接”。连接 ID 和原映射模板保留，验证记录作废；重新刷新目录并应用/确认当前文件映射后，再开始新任务。

新版 notebook 为每个真正启动的 ComfyUI 进程生成独立实例 ID，同一活进程重跑保持不变。网关、连接 JSON 和本地认证请求核对同一 ID。服务在同一地址重启时，旧连接也会被拒绝；旧任务不会被误发到新实例，也不会自动重提 `/prompt`。

优先导入完整连接 JSON。普通 HTTPS 地址仍受支持；没有可核验实例标识的服务按弱身份处理，不能承诺识别同一地址背后的所有重建。旧网关、本机和 SSH 的既有流程继续兼容。
