本轮已到可开始人工测试的状态；未对外发布，默认仍是经典工作台。此次重点是日常操作是否顺手、要求是否大体保持，不要求逐图完美。

alpha.2 修复：LLM 设置可刷新服务商模型目录、搜索并下拉选择。使用“刷新模型列表”后搜索名称，选中目标，再点击“保存配置”。刷新不会改变当前模型，也不会调用文本生成；地址或 Key 有改动时先保存。OpenCode 已实测返回 36 个模型。

## 从哪里开始

- 继续使用现有模型和云端配置：关闭旧的本地应用服务，双击项目根目录的 `启动 ANIMA V3.cmd`，在工作台点击“试用会话创作”。
- 测试发行体验：使用 `release/ANIMA-Prompt-Studio-V3-Setup-v3.0.0-alpha.2.exe`，或解压同目录的 Portable ZIP，再运行 `AnimaPromptStudioV3.exe`。ZIP 必须完整解压。
- 项目启动器和发行包的默认配置目录不同。发行包不会自动复制项目 `v3/.local/prompt-assistant` 中的 LLM 设置；首次使用需在界面确认模型配置。不要同时开启多个实例对同一组数据进行测试。
- 经典入口和会话试用入口都保留。未默认开放的功能不代表数据被清除。

## 建议按这个顺序试

1. **新建与改写**：描述一人、服装、动作和场景，使用忠实模式发送；确认正负提示词大体完整。然后只改光线、再改背景，观察其他核心要求是否保留。保持非思考模式。
2. **锁层与手改**：锁定主体后再次修改背景；手动修改英文提示词并复制。保存、刷新、切换会话再回来，确认输入和已保存内容正确恢复，没有无故提示未保存。
3. **参考复用**：展开参考收藏，安装内置样例，选择木刻或水彩并检查覆盖预览；只复制风格时，不应把参考人物一起带入。也可上传自己的图，粘贴原始提示词并提取，核对后人工修正。
4. **生成参数**：选择实际模型/工作流与生成目标，调整 seed、尺寸或采样参数。更换模型后核对配方是否合适；只改 CFG 或步数不应改变画幅。
5. **生成与恢复**：先生成一张，观察任务状态与成图，刷新后应仍能找到任务和结果。检查画廊预览、结果收藏，必要时再试一次重新生成；不要为测试连续重复提交大量图片。
6. **日常易用性**：检查页签切换、长提示词阅读、复制反馈和折叠设置。记录找不到入口、误点、文字难读等情况。

读图建议仅是可选辅助，不作为主力或必须通过的项目。少量术语偏差、可修正细节遗漏可以记录；数量、身份、否定关系出错值得重点反馈。提示词正确而成图手势或裁切不准，单独记为 ANIMA 执行偏差。

## 怎样反馈最有帮助

每个问题记录：操作入口、输入内容、期望结果、实际结果、使用的 LLM/生图模型。若与成图有关，附正负提示词、seed 和图片；若与保存或任务有关，附操作顺序和错误提示。不要附 API Key 或 SSH 密码。
