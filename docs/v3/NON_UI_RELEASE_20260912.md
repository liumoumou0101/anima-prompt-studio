## 参考数据的可信边界

124 条来源中：34 条明确无 LoRA，62 条明确含 LoRA，28 条依赖未知。所有来源缺少原始种子和完整工作流，这些字段保持未知；不以程序默认值伪装来源参数。借用原提示词使用对应已知模型的程序默认参数，未知模型采用当前受支持配置，不携带未安装的来源 LoRA；有完整原任务快照的本机生成结果才可“沿用生成条件”。

重复导入 124 条全部 unchanged；原图哈希一致，原 `anima-ref` 文件未改。导入器保留个人标题、笔记、已编辑要求、兼容性和删除状态。原资料汇总文档的 LoRA 数字存在历史错误，交付按结构化记录分类。

词库收录、收藏和一次好图不代表模型已经学会某个身份。短语识别也不是语义解析，可能命中同形词或否定句里的词，需要核对推荐依据。实测笔记只表示那张图的人工观察，不自动转换为模型认识概率。

## 用户验收顺序

1. 打开现有会话，保留一段未发送想法。到标签库选择角色和普通标签并带入，确认原内容仍在；撤销一次，再试“带入新会话”。画师详情也可加入当前会话。
2. 在画面要求中展开手动 tag，输入“初音未来”、`frieren`、`fuzichoco`；用上下键和 Enter 选择，试收藏和自定义别名。对词库外名字直接保存，再编译查看原 tag 是否保留。
3. 到参考案例筛选纯底模／LoRA／未知，查看图片和来源参数；点击“借用原提示词，新建会话”，核对正负原文。此操作无需调用模型。
4. 正常选择生成目标和配方后，自行完成 Aesthetic、Anima 2.9B、Yume 1.5 的图片效果验收。可使用“记录人工实测”保留问题，再从参考记录继续。功能测试通过不等于模型画质已验收。
5. 新开一个同源标签页、刷新页面，检查会话恢复；关闭应用再从桌面入口打开，检查已保存会话和未发送草稿。服务端重启后仍需桌面启动链接完成一次正常登录。

## 本机数据与跨电脑交接

| 内容 | 本机位置 | 交接方式 |
| --- | --- | --- |
| 可编辑会话、参考索引、收藏／别名 | `v3/.local/state/` | 停止应用后整体复制此目录；包含 workspaces.db、examples.db、identity-preferences.db、example-media、official-examples。SQLite 在运行时不能只拷主文件而丢弃 WAL。 |
| 只读词库 | `v3/.local/data/` 与 `v3/.local/packs/` | 使用版本化数据包安装，当前为 anima-v3-dso-0636f762-r1。发行包携带词库。 |
| 原始研究资料 | `anima-ref/` | 另行复制，再运行 `v3/tools/import_reference_collection.py --source anima-ref --database v3/.local/state/examples.db`。当前资料未通过代码同步自动分发。 |
| 运行配置／历史任务 | `%LOCALAPPDATA%/AnimaPromptStudio/anima_prompt_studio.db` | 停止服务后备份；另一台机器重新配置服务器和本机资源路径。 |
| 生成图片 | 原配置的 Pictures/AnimaPromptStudio 等目录 | 图片单独复制；路径改变后原历史资源可能需重新定位。 |
| 未发送的浏览器草稿 | 对应本地地址的浏览器存储 | 在迁移前先保存要求；浏览器本地草稿不会随 Git 或数据库自动迁移。 |

标准安装包不携带个人会话、云主机密码或用户研究图片。本机验收优先使用项目入口以沿用已导入的 127 条案例。API Key、SSH 凭据仍按本机凭据管理方式重新配置，不放进代码或发行包。

本轮备份及验收回执：`.local/non-ui-release-20260912/`。其中 `backup/` 是导入前 SQLite 备份；`reference-import.json`、`reference-reimport.json` 记录实际导入；`acceptance/` 是隔离浏览器验收环境。桌面端口记录位于 `workspaces.db.local-api.json`，本机沿用升级前的 9534；复制数据到另一电脑时，该端口只作首选，系统占用时会安全回退。
