# MOSS 中文多画风工作台 · 第一版

2026-10-27。提供独立的「MOSS 工作台」，支持中文原文、只整理润色和创意扩写。与 ANIMA 共用临时连接、生成任务、运行记录与画廊。

## 开始使用

1. 重新运行项目根目录的 `启动 ANIMA V3.cmd`，在左侧打开「MOSS 工作台」。本轮更新源码和网页构建，未重新打包 EXE。
2. 打开原 Colab 笔记本，准备单元的 `MODEL_ID` 选择 `moss_image_sft_int8`，依次运行挂载、准备、启动和云端 API 单元。已有 Drive 权重会复用。
3. 在 Colab 下载本次 `/content/moss_connection.json`，到本地「设置 → 导入临时连接」导入。换环境时更新原连接，之后重新核验资源。
4. 回到「MOSS 工作台」，明确选择这次 Colab 环境。首次使用可「刷新云端目录 → 应用当前工作流文件映射」；出图检查若显示资源身份待确认，核对模型后点击确认并继续原请求。
5. 写中文描述，选择处理方式，确认画幅和参数后点击「生成图像」。任务和图片仍在共用的任务页与画廊。

不要把 Colab 笔记本网址作为 API 地址。密钥保存在 Windows 凭据管理器；本工作台草稿只保存创作内容和非秘密连接标识。

## 三种处理方式

| 方式 | 行为 |
| --- | --- |
| 原文直接出图 | 原文直接交给 MOSS；不调用 LLM，不翻译，不加入 ANIMA 标签。 |
| 只整理润色 | 改善表达和顺序；要求保留已明确的可见内容，不补新场景。 |
| 创意扩写 | 允许在未指定处补适量兼容细节，例如光线、背景、服饰材质；逐项列出改动。 |

辅助模式使用项目已有的 LLM 设置。「获取建议」只产生可编辑建议，原文一直保留。先检查改动和提醒，点击「采用建议」，再单独点击「生成图像」。也能随时「使用原文」。修改原文、排除内容或模式后，旧建议失效，晚到的响应不会覆盖新内容。

两种辅助都要求保留主体、数量、身份、颜色、服饰、动作、左右关系、指定画风、构图和排除项。程序会校验引号内文字及排除内容；其他语义仍需在建议区审阅。已有完整描述可能原样返回，扩写不保证每次都需要新增。

适合直接描述混合画风，例如：

> 一位成年女性，银色长发，深蓝色宫廷礼服，坐着。洛可可宫廷肖像的二次元版本，厚涂。

## 模型与参数

当前支持 `MOSS-Image SFT INT8`，默认 1024×1024、25 步、CFG 2.5、er_sde / simple，原生 shift 5。宽高必须为 16 的倍数。

所需文件：

- `moss_image_sft_int8_convrot.safetensors`
- `qwen3.5_9b_w4a8_gptq.safetensors`
- `flux2-vae_small.safetensors`

模型、文字编码器和 VAE 使用 MOSS 专用组合；ANIMA 的文件映射和草稿不会自动套入此页面。目录中显示「文件齐全」只说明文件就绪，真实运行结果以任务为准。

## 恢复与范围

网络状态不明时点击「继续原请求」，会沿用原来的请求凭证和冻结内容。接受任务后环境与内容固定；修改页面不会暗中改变已提交任务。运行实例变化时仍沿用第一版的身份核验，更新连接后重新检测。

首版是独立 MOSS 文生图与两种可选 LLM 辅助，后续可根据画风对照再调整。图生图、布局编辑器、MOSS LoRA、高清修复及安装包重打包不在本轮范围。
