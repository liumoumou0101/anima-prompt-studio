## 真实页面发现并修复的附加问题

放大时上传成功后，LoadImage 的静态枚举仍可能不列出新上传子目录文件，导致旧预检误拒绝。V2/V3 ComfyUI 客户端现在仅认可该客户端收到的成功上传回执的确切路径；其他未上传文件、放大模型、LoRA 等枚举仍然校验，服务端仍负责最终工作流校验。最初失败发生于远端 prompt 提交前，修复后重新点击成功。
