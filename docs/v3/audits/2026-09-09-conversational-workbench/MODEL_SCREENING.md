# 同场景模型初筛（2026-09-10）

用户明确选择质量优先：不再围绕单个模型反复修改规则；难以遵循要求的候选可以放弃，套餐内较贵模型也可测试。本轮冻结木刻场景和现有 SYSTEM，只切换进程内模型，不改变用户保存的默认配置。

模型列表从当前套餐 `/models` 读取，HTTP 200；同时核对 [OpenCode Go 官方列表与接口说明](https://opencode.ai/docs/go/)。列表存在不保证真实路由和每次可用性，尤其不能把先前 GLM 别名路由问题推广成其他模型也一定如此。测试记录的是请求模型 ID，不伪称已验证上游权重身份。

## 方法

使用 `evaluate_conversation woodcut --model …`，每个候选独立新工作台，顺序跑首编、加逆光、expand 三轮。每轮审阅实际正向，不只看中文要求层和 warnings。API/结构失败会立即停止；语义问题在捕获后人工判定。没有自动重试、自动换默认模型或修补输出。后端规则与契约相同，温度 0.7、top_p 0.9、max_tokens 4096，均启用高级参数；各模型对参数的实现未必相同。
