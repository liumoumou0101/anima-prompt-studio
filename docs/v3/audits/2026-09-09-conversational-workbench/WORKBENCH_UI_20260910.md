# 工作台界面与交互收尾

日期：2026-09-10。用户授权继续开发，并改善工作台 UI。本轮以现有深色紫色主题整理信息层级，不追加模型效果试验。

## 改动

- 经典工作台增加“试用会话创作”入口，默认收起 LLM 与高级生成设置，减少重复侧栏与首屏配置密度。
- 会话页明确分成创作对话与画面工作区；提示词、画面要求、生成设置改为页签，保存与生成操作统一置于底部。
- 提示词复制提供反馈；初次创建可先填写想法或选示例，创建不会自动调用 LLM 或生成图片。
- 五层锁定具有独立可访问名称；页签支持方向键、Home/End；统一导航图标与窄屏可读名称，390px 下纵向排列并避让底部导航。
- 明示生成不可用的原因，提供生成目标设置和服务器管理入口。
- 修复保存状态比较：缺省生成设置使用一致默认值，JSON 对象按字段内容比较，字段顺序不再制造未保存状态。
- 手动修改生成参数标记自定义配方，仅修改宽高时改变画幅类型。

## 验证步骤与结果

1. 对照改动前经典页和会话页截图：原先配置层级混杂，改后低频选项折叠、核心编辑与结果位置清楚。
2. 桌面会话页切换三组页签、复制正向提示词：输入保留、复制反馈正常。
3. 切换主体锁定，保存并刷新：持久化恢复正常；恢复原值再次保存后不再误报未保存。
4. 检查生成设置、不可用原因与跳转入口：可编辑；隔离预览未连接生图服务，未验证本轮真实 GPU 提交。
5. 390px 窄屏检查：会话页无横向溢出；桌面浏览器控制台无错误或警告。本轮仅检查上述键盘与名称行为，不声明完整无障碍合规。
6. 前端 14 个测试文件、72 项测试通过；TypeScript 与正式构建通过。构建仍有现存大 chunk 提示。新增回归覆盖缺省设置、页签/复制、创建不自动调用、自定义参数与字段排序后的保存状态。

后端最近一次全量为上一批的 433 项通过，本轮未改后端、未重复后端全量。没有新增 LLM 或 GPU 调用，没有修改默认发布 flags。
