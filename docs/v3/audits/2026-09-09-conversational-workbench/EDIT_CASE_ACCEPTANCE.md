## 参数兼容修复

[Z.AI 官方思考文档](https://docs.z.ai/guides/capabilities/thinking) 明确 GLM-5.3 与 5.3-Flash 不再支持关闭思考。原注册规则按 GLM-5 前缀匹配，错误发送 `thinking.type=disabled`。

现在这两个已知版本不再匹配禁用参数。会话的 rewrite、prompt_ingest、probe，以及未启用思考的可选 ingest，会在联网前返回 `thinking_disable_unsupported`，提示选择其他文字模型。只有显式启用 ingest 思考时才允许该模型继续可选分析，且不发送 disabled。不通过静默开启思考绕过文字任务的设置。

测试覆盖三个名称变体、四类任务的零网络拒绝、GLM-5.2 原有控制保留、启用思考的可选分析，以及 API 的 422 错误和草稿保护。此处不推断其他未知模型或代理都具备相同能力。
