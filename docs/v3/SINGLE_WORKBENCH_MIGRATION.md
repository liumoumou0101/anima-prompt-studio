# 单一工作台迁移与交付边界

日期：2026-10-25。本轮在 `codex/single-workbench-20261025` 隔离工作区实现并验证，源码和 Web 构建同步至本机原目录 `H:/soft/提示词工具2`。原有未提交修改保留；同步前的程序文件备份及逐文件哈希清单位于 `reports/single-workbench-implementation/rollback-*`。运行中的旧进程没有被强制关闭，重新通过“启动 ANIMA V3.cmd”打开即可加载本轮版本；安装包未重新制作，个人配置和数据库未替换。设计依据为[单一工作台方案](../superpowers/specs/2026-10-25-single-workbench-design.md)与[实施计划](../superpowers/plans/2026-10-25-single-workbench.md)；下文以实际代码为准，方案中的建议不能直接当作验收结果。

## 入口与日常操作

`/workbench` 是唯一编辑工作台；`/workbench/conversation` 保留兼容入口，使用同一组件。`/direct` 只负责恢复原文草稿、保留待确认请求并转入统一工作台，不再挂载另一套编辑与生成控制器。原英文编辑、中文修改、正负提示词、要求和锁定均在同一创作中使用。

桌面保留编辑区，右侧在结果、参数、版本之间切换；小于 1024 CSS px 时使用单栏提示词/图片视图。底部生成条在布局流中。导航可收为 76 px 图标栏或展开为 196 px；更窄屏幕使用顶部导航。浅色、夜间、跟随系统继续保留，旧 studio/editorial 偏好读为 unified，不再提供布局选择。

“更新提示词”执行改写；“生成图片”使用当前编辑文本与参数。尚未应用的意见保留并提示，不会因为点击生成而隐式改写。“更新并生成”是显式次级动作；改写失败、基点改变或生成检查失败时不继续后半段。英文直出无需配置改词 LLM；字典/翻译对照是只读预览，不把中文结果覆盖正文。

## 能力去向

| 原有能力 | 当前入口与范围 |
| --- | --- |
| 会话选择、命名、归档、草稿找回 | 工作台顶部与“查找与管理会话”；本地恢复入口位于创作记录区域 |
| 正负提示词、中文意见、改写方式、要求、内容锁定 | 同一编辑区、意见区和创作工具；提示词片段锁定与分层要求锁定保留各自语义 |
| 角色、作品、手动画师标签、场景设计、画师推荐 | 工作台创作工具；原标签、画师页面仍可独立浏览 |
| 标签、个人标签、参考导入 | 保留 `/tags`、`/personal-tags`、`/references` 及原有预览/带入/撤销链路；不同写入目标没有合并成一种动作 |
| 图片预览、单图对照、读取参数、继续创作 | 工作台结果区、画廊与任务页；缺失值显示未知，不补造 Seed 或资源 |
| 模型、配方、LoRA、基础与工作流参数 | 模型/创作工作流入口及参数面板；执行环境是独立策略 |
| 模板、JSON、环境资源映射 | `/workflows` 的本地模板及执行环境视图；未知复杂图继续使用高级 JSON |
| 任务进度与恢复 | `/generate` 展示来源提示词、来源修订、缩略图与继续入口；技术 ID 放详情。继续只建创作，不调用改写或自动生成 |
| 旧 `WorkbenchPage.tsx` 独有流程 | 源文件与相关逻辑保留，但不在主路由；见下方限制，不能据此宣称已全部迁入新界面 |

旧工作台的本地候选编译、旧式场景事实归属、同 Seed 批量画师对照及独立本地翻译流程没有作为另一套工作台重新开放。统一页已接入只读字典/翻译对照、场景工具和图片对照，但这些入口不能作为旧流程逐项等价替代的证明。未完成能力去向确认之前，不删除旧实现。

## 撤销、版本与恢复

三类操作的范围不同：

| 动作 | 恢复范围 | 保留范围 |
| --- | --- | --- |
| 撤销/重做 | 操作实际改变的字段；有效 AI 改写分别成步，连续同字段文本短时间合并 | 后来未被该操作改变的执行字段、用户新输入的意见、生成记录与图片 |
| 提示词版本“用此版本继续编辑” | 正负文本、改写方式、内容要求与锁定；旧快照缺失内容背景时清理不匹配的记忆 | 当前模型、工作流、采样参数、LoRA 绑定与执行策略 |
| 图片“从这张继续” | 已记录的内容、模型、工作流快照、基础与工作流特有参数、实际 Seed 和资源要求 | 当前执行策略；不会因恢复图片而自动生成，也不会强制复活原云实例 |

图片还有“只用提示词”动作；缺少完整参数时不能进行完整恢复。随机旧记录或多图批次的提交 Seed 不保证精确对应某一张图片；未知实际值仍显示未知。

快捷链正常保留最近 50 步；被截断的步骤与被新分支替代的重做步骤保留完整恢复快照。草稿、基准、日志与待同步 outbox 在 localStorage 的完整记录中保存，并写入包含相同材料的 IndexedDB 单事务副本。IndexedDB 回退仅沿当前文档明确的重载/复制来源读取，不搜索其他窗口的最新可写游标。存储故障会提示并保留已有恢复材料；未落盘的最后输入不承诺断电恢复。

服务端 checkpoint 使用稳定 operationId 去重并分配持久 V 编号；待同步项显示“本地版本”。旧工作区修订快照仍保留，修订号不冒充用户版本号。图片保留原 run/输入/工作区修订关联，不按列表位置或 baseRevision 猜测 checkpoint 对应关系。

当前新 checkpoint 提供“用此版本继续编辑”；主页面未接入其独立“另开创作”回调。旧修订快照的另开会话入口仍保留。恢复前先备份当前完整草稿；恢复本身可撤销，恢复回执采用稳定操作 ID 与 revision CAS。来自本窗口的正常保存保留快捷链；远端基点改变或冲突合并会把旧链留作恢复记录，再建立当前基点。

改写请求按工作区和文档隔离上下文 token。取消、恢复和切换基点使旧请求失效；后端在调用前及最终写入事务中复查 token。其他窗口仍受 revision CAS 约束。取消浏览器请求不被当作“后端肯定没有写入”的证明。

## 参数、配方与环境

创作配置保存模型、工作流及版本、配方基线、逐字段覆盖与资源要求；执行策略另存为 auto/pinned。换环境不应用配方，也不改写 Seed、LoRA 或采样参数。

配方先列改变项，用户显式应用，一次操作可撤销；未列出的字段保持原值。字段保留推荐值、已修改状态和单项恢复入口。数字编辑允许暂时为空，错误输入留在编辑区并阻止生成，不自动变成 0。Seed 以精确十进制文本处理，随机使用明确模式。更换模型/工作流保留兼容值，不兼容项需要用户解决后才能提交。

工作流参数来自版本化声明及受校验的节点输入绑定。基础字段包括尺寸、张数、Seed、Steps、CFG、Sampler、Scheduler。只有模板声明高清第二阶段时才出现精修步骤、CFG、采样器、调度器、降噪与倍率；第二阶段 Seed 沿既有派生规则。随附模板目前没有高清模板，合成测试覆盖不等于实机高清出图通过。接受时冻结声明、解析值、工作流图与资源映射；历史继续使用冻结版本，避免随今天的模板漂移。

新创作默认 auto。旧草稿保存了环境 ID、但来源无法证明是默认还是手选时，保守保留为 pinned；用户可显式切到 auto。auto 按偏好、最近成功和稳定配置顺序检查候选，pinned 只检查指定环境，不静默回退。

路由检查最多并发 2 个候选，单候选预算 5 秒、单轮 15 秒；连通性证据最多复用 30 秒、能力证据最多 900 秒，网络失败退避 30/60/120 秒。未检查的游标保留，继续检查仍使用同一个意图。大型资源检测未完成显示待检测，并可进入既有异步检测流程，不能因在线就接受任务。

SSH 主机指纹仍需确认；实例身份、配置或 epoch 变化会使旧证据失效。“此环境已重建”用于显式失效旧映射。弱身份环境必须刷新能力并取得当前资源确认，文件同名不被当作权重相同；确认有时效限制。无法读取稳定身份时，不能承诺发现所有同地址重建。旧冻结版本的确认绑定到对应意图与实际冻结图。

生成意图使用稳定客户端键和冻结请求体；同键不同内容返回冲突。意图接受、冻结目标、submission 与 intent→run 映射在同一工作区数据库事务内落盘，并检查解析租约、源修订和资源身份。接受后不跨环境重发；丢响应、刷新或重启先查询原意图/提交，保留原键，不能把“状态未知”当成“未生成”。

## 旧数据迁移与回退

- 会话、旧修订、图片、run ID 与原参数不做破坏性批量重写。日志、上下文、checkpoint、恢复回执和意图表以增量方式加入；浏览器 bundle/journal 带版本字段。
- 旧 localStorage 草稿迁入当前状态，不捏造过去操作。复制窗口恢复只读来源后使用自己的文档身份，不共用可写游标。损坏原始字节保留，不能按“没有草稿”覆盖。
- `/direct` 保留原 legacy JSON。项目名、模型、精确 Seed、设置及已有中文对照经稳定摘要身份迁入，成功写入后才记录消费回执。空正向草稿仍保留项目/参数与负向文本；没有英文正向时不伪造可生成文本。
- 原文新建前备份当前草稿；失败保留入口与原请求，显式重试复用原键/请求体。不会自动重试生成。旧版若只把请求键留在已经关闭窗口的内存里，无法凭空还原；已持久化的旧 pending 原样保留并先核对任务。
- 旧 flat pending 与新 intent 请求分别识别；升级不会替它们换键、换请求体、换协议或重新选环境提交。

回退前保留工作区数据库、运行库及浏览器恢复材料；SQLite 在线备份应使用一致性备份方式。不能只复制运行中的主 `.db` 而忽略其事务状态，也不能通过清空日志、意图或 pending 来“恢复可用”。运行库旧版本升级沿用既有备份机制；这不代表所有新增表迁移都有独立自动备份。

回退 UI 不删除新增历史或接受记录。旧后端不保证理解新的配置字段；若必须整体降级，应先停止相关写入并使用对应版本备份，不能让旧服务继续写入新格式再声称无损回退。源文件保留不等于已提供旧布局运行开关。
