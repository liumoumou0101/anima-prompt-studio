# V3 产品基线

状态：已确认，可用于开发拆分

版本：V3.2-prep

## 1. 要解决的问题

V2 已完成中文输入、提示词编译、远程 ComfyUI 生图、下载和画廊闭环，但默认编译结果的实际出图效果经常不如从内容创作者处复制的成熟提示词。

V3 的首要目标不是“生成更多标签”，而是提高以下三项的综合结果：

1. 用户意图保真：明确的人物、服装、动作、数量、关系和排除项不被改变。
2. 模型分布适配：正确使用 ANIMA 认识的标签、结构、画师格式和模型专用模板。
3. 可验证的实际效果：在固定模型与固定参数的生图对比中，默认候选显著优于 V2，并接近外部优秀提示词的可用下限。

## 2. 产品定位

V3 是本地优先的 ANIMA 提示词工作站：用户可以输入中文或英文描述，获得多种有明确差异的完整提示词候选，理解每个候选为何添加或删除标签，手工浏览全量标签和画师，并把选定候选送入已有 ComfyUI 生图与画廊闭环。

V3 首版只保证 ANIMA Base、Aesthetic 和 Turbo，不建设通用多模型统一推荐引擎。

## 3. 核心用户任务

### 3.1 从中文描述得到可生成候选

用户输入画面描述后，系统输出：

- 基准候选：准确映射和格式化，不做共现扩展，不自动添加画师。
- 保守增强候选：只添加少量高置信、无冲突的相关标签。
- 风格候选：在保守增强基础上加入一个用户可移除的推荐画师。
- 混合表达候选：标签负责稳定概念，自然语言负责关系、空间和复杂动作。

候选数量首版默认为 3 组；当混合表达确有必要时可以输出第 4 组。不得为了凑数量制造只有排序不同的近重复候选。

### 3.2 浏览和选择标签

用户可以：

- 搜索 4 万以上标签，支持英文、中文、别名、前缀、子串和拼写容错。
- 按 General、Artist、Copyright、Character、Meta 过滤。
- 打开标签详情，查看说明、别名、分类、热度、相关标签和可选在线预览。
- 把标签加入当前工作台，设为必需、排除、建议或锁定。
- 查看某个自动标签的来源、置信度、共现依据和影响范围。

### 3.3 探索画师

用户可以搜索画师、查看擅长标签、共现依据和可选预览。画师只有在用户选择或选择风格候选时才进入最终提示词。

### 3.4 选择候选并生成

用户可以并排比较候选，查看正向、反向、画师、保留项、扩展项、警告和分数分解，编辑后送入本地或远程 ComfyUI。生成结果进入现有画廊并保存完整快照。

## 4. 页面范围

| 路由 | 首版能力 |
| --- | --- |
| `/workbench` | 输入、结构化意图、约束、候选生成和人工编辑 |
| `/tags` | 全量标签浏览、搜索、过滤、勾选和批量操作 |
| `/tags/:name` | 标签详情、别名、Wiki、相关标签、预览 |
| `/artists` | 画师搜索、推荐、擅长标签和预览 |
| `/generate` | 候选对比、参数快照、提交和队列状态 |
| `/gallery` | 历史图片、筛选、比较、回收站、再生成和放大 |
| `/settings` | 模型、数据包、联网、NSFW、远程连接和更新设置 |

首版不要求 SEO、公开部署、用户账户、多人同步和云端工作区。

## 5. 提示词领域对象

单纯的 `must_keep: bool` 不足以表达复杂约束。V3 使用结构化意图对象：

```text
IntentElement
  id
  source_span
  original_text
  canonical_tag?
  entity_id?
  type
  relation?
  cardinality?
  state: required | excluded | suggested | locked
  confidence
  provenance
```

约束优先级：

```text
locked > excluded > required > user_selected > suggested > automatic
```

任何自动增强都不得覆盖 `locked`、重新引入 `excluded`，或静默删除 `required`。无法同时满足时返回冲突，不自行猜测。

## 6. 模型专用输出

模型配置是提示词生成和远程执行的共同输入，而不是生成结束后的装饰参数。

每个 `ModelProfile` 至少定义：

- 模型家族、版本和变体。
- 内部 canonical tag 到最终文本的渲染规则。
- 正向前缀、反向模板及是否使用 `score_*`。
- 画师 `@` 规则。
- Steps、CFG、Sampler、Scheduler 和尺寸建议。
- 支持的 ComfyUI 工作流。

内部标签可使用 `school_uniform` 作为稳定 ID；ANIMA 输出层通常渲染为 `school uniform`。`score_7` 等模型规定的例外保留下划线。

## 7. 离线与联网

离线必须可用：

- 标签、别名和分类搜索。
- 标签详情中的本地说明。
- 相关标签和画师推荐。
- 本地翻译、候选组装、历史和收藏。
- 已下载图片的画廊管理。

按需联网：

- 软件和参考数据包更新。
- Danbooru Wiki 刷新和帖子预览。
- 用户主动调用的 AI 辅助抽取。
- SSH 云主机和 ComfyUI 生图。

联网功能失败不得阻断离线标签与提示词主路径。

## 8. 明确非目标

- 不训练、微调或捆绑 ANIMA 模型。
- 不替代 ComfyUI 工作流编辑器。
- 不在首版自动从图片质量反向训练排序模型。
- 不把 Danbooru 在线服务作为日常搜索的必需依赖。
- 不承诺纯文生图稳定完成任意复杂多实体空间关系。
- 不自动选择用户未授权的模型、LoRA 或远程主机。

## 9. 产品成功条件

正式版需同时满足：

1. 基准候选不会因为共现扩展而偏离输入；明确要求与排除项有可追踪结果。
2. 在固定参数盲测中，V3 默认候选对 V2 有稳定、可复现的提升。
3. 用户可以完整浏览标签和画师，不依赖小型弹窗完成主要工作。
4. 无网络时可以完成“输入—候选—编辑—复制”的完整链路。
5. 数据包可验证、可回滚；用户历史不随参考数据更新丢失。
6. 远程生成继续满足 V2 已验证的主机指纹、凭据、恢复和下载安全约束。
